# Switch

<Localized
  en={
    <>
      <p>
        The <strong>Switch</strong> atom is the native{' '}
        <code>&lt;input type="checkbox" role="switch"&gt;</code>, drawn by CSS as a track
        and a thumb, inside a <code>&lt;label&gt;</code>. Its <code>children</code> are
        the visible label, placed after the track, so the whole row is the click target,
        and Space, focus and form posting stay native. The state is the native{' '}
        <code>checked</code>; the atom never renders <code>aria-checked</code>, which ARIA
        in HTML forbids on this input.
      </p>
      <p>
        A switch takes effect immediately, like a light switch: use it for a setting that
        applies the moment it changes. In a form the user submits, prefer Checkbox. A
        switch has no mixed state, so there is no <code>indeterminate</code>.
      </p>
      <p>
        A switch without children has no visible label: give it an accessible name with{' '}
        <code>aria-label</code> or <code>aria-labelledby</code>. The types do not enforce
        it, so check every bare switch. Keep the label stable: it names the setting, not
        its current state.
      </p>
      <p>
        Use <code>variantSize</code> for scale (<code>sm</code>, <code>md</code>,{' '}
        <code>lg</code>, the same scale as Checkbox). <code>invalid</code> sets{' '}
        <code>aria-invalid</code> and a danger border; colour is never the only signal, so
        pair it with an error message in text. <code>readOnly</code> has no effect on a
        checkbox-type input (MDN): use <code>disabled</code> instead.
      </p>
      <p>
        The atom is display only (ADR 0016): it ships no validation and no error text.{' '}
        <code>name</code>, <code>value</code>, <code>checked</code>,{' '}
        <code>defaultChecked</code>, <code>required</code>, <code>onChange</code>,{' '}
        <code>onBlur</code> and <code>ref</code> reach the native input, so React Hook
        Form's <code>register</code> and <code>FormData</code> work as on a plain
        checkbox. <code>className</code> and <code>style</code> land on the root{' '}
        <code>&lt;label&gt;</code>.
      </p>
      <p>
        On, the track takes the accent fill and the thumb slides to the end; the thumb
        position carries the state, not the colour alone. On hover the track lifts by one
        pixel, on press it drops by one pixel (ADR 0009). Focus draws the focus ring
        around the track. A disabled switch gets a dashed border. All motion respects{' '}
        <code>prefers-reduced-motion</code>. A long label wraps next to the track, down to
        320 CSS px.
      </p>
    </>
  }
