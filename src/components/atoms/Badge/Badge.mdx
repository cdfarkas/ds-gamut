# Badge

<Localized
  en={
    <>
      <p>
        The <strong>Badge</strong> atom is a short, non-interactive status label. It
        consumes semantic <code>var(--…)</code> tokens only, so it reskins across the
        light/dark theme axis and the neutral/pixel skin axis without any change to its
        own CSS.
      </p>
      <p>
        Use <code>intent</code> for meaning (<code>primary</code>, <code>neutral</code>,{' '}
        <code>success</code>, <code>warning</code>, <code>info</code>, <code>danger</code>
        ). The status intents <code>success</code>, <code>warning</code>,{' '}
        <code>info</code> and <code>danger</code> draw on the global status tokens{' '}
        <code>--omnia-color-&lt;status&gt;</code> /{' '}
        <code>--omnia-color-text-on-&lt;status&gt;</code> (ADR 0012), shared by any
        component that carries a status. Every intent reads its colours from the shared
        intent map (<code>--omnia-intent-bg</code>/<code>--omnia-intent-fg</code>, ADR
        0012). Colour is never the only signal: the badge text itself must carry the
        meaning, so it still reads without colour. A badge is not a control — it has no
        hover, press or focus state; wrap it in a real control when it must act.
      </p>
    </>
  }
  fr={
    <>

        <code>--omnia-color-text-on-&lt;status&gt;</code> (ADR 0012), partagés par tout
