# Input

<Localized
  en={

      <p>
        The <strong>Input</strong> atom is the bare single-line text control: the native{' '}
        <code>&lt;input&gt;</code> plus optional start and end adornments. It carries no
        label, hint or error message; those belong to a wrapping field (a{' '}
        <code>FormField</code> molecule is planned). Until then, give every input an
        accessible name yourself, with a <code>&lt;label htmlFor&gt;</code> or{' '}
        <code>aria-label</code>. A placeholder is never a label.
      </p>
      <p>
        Use <code>size</code> for scale (<code>sm</code>, <code>md</code>, <code>lg</code>

        <code>text</code>, <code>email</code>, <code>url</code>, <code>tel</code>,{' '}
        <code>password</code>). <code>invalid</code> sets <code>aria-invalid</code> and a
        danger border; colour is never the only signal, so pair it with an error message
        in text. An input has no <code>intent</code>: invalid is its own state.
      </p>
      <p>
        <code>className</code> and <code>style</code> land on the root wrapper, the
        visible box. Every other prop, <code>ref</code> included, lands on the native{' '}
        <code>&lt;input&gt;</code>, so <code>id</code>, <code>name</code>,{' '}
        <code>autoComplete</code> and <code>aria-*</code> work as on a plain input.
        Adornments are decorative unless you give them meaning: mark an icon{' '}
        <code>aria-hidden</code>, and keep the unit or prefix in the label too.
      </p>
      <p>
        On hover and focus the field lifts and its offset shadow grows (ADR 0009); focus
        also draws the focus ring around the whole field. Disabled and read-only stay
        flat; a disabled field also gets a dashed border, so the two differ without
        colour. All motion respects <code>prefers-reduced-motion</code>. The field fills
        the width it is given, down to 320 CSS px.
      </p>
