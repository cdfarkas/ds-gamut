# Checkbox

<Localized
  en={
    <>
      <p>
        The <strong>Checkbox</strong> atom is the native{' '}
        <code>&lt;input type="checkbox"&gt;</code>, drawn by CSS, inside a{' '}
        <code>&lt;label&gt;</code>. Its <code>children</code> are the visible label, so
        the whole row is the click target, and Space, focus, form posting and the
        accessible role all stay native.
      </p>
      <p>
        A checkbox without children has no visible label: give it an accessible name with{' '}
        <code>aria-label</code> or <code>aria-labelledby</code>, as in a table row
        selector. The types do not enforce it, so check every bare checkbox.
      </p>
      <p>
        Use <code>variantSize</code> for scale (<code>sm</code>, <code>md</code>,{' '}
        <code>lg</code>, the same scale as Input). <code>invalid</code> sets{' '}
        <code>aria-invalid</code> and a danger border; colour is never the only signal, so
        pair it with an error message in text.
      </p>
      <p>
        <code>indeterminate</code> shows the mixed state, for a "select all" over a
        partial selection. It sets the DOM <code>indeterminate</code> property, which has
        no HTML attribute, and never changes <code>checked</code>: the form value is
        whatever <code>checked</code> says. A click clears the mixed state in the browser;
        the atom puts it back as long as the prop stays <code>true</code>, so set it to{' '}
        <code>false</code> in your <code>onChange</code> when the selection changes.
      </p>
      <p>
        The atom is display only (ADR 0016): it ships no validation and no error text.

        <code>onChange</code>, <code>onBlur</code> and <code>ref</code> reach the native
        input, so React Hook Form's <code>register</code>, <code>FormData</code> and React
        19 actions work as on a plain checkbox. <code>className</code> and{' '}
        <code>style</code> land on the root <code>&lt;label&gt;</code>.
      </p>
      <p>

        colour. All motion respects <code>prefers-reduced-motion</code>. A long label
        wraps next to the box, down to 320 CSS px.
      </p>
